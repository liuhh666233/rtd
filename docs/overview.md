# RTD (Rust Todo) 项目概述

RTD 是一个使用 Rust 语言开发的命令行待办事项管理工具。它提供了简单而强大的功能，帮助用户管理他们的待办事项。

## 主要特性

1. **基本操作**
   - 添加新的待办事项
   - 标记待办事项为完成/未完成
   - 删除待办事项（支持软删除）
   - 恢复已删除的待办事项
   - 永久删除待办事项

2. **列表查看**
   - 查看所有待办事项
   - 查看已完成的待办事项
   - 查看未完成的待办事项
   - 查看已删除的待办事项

3. **数据持久化**
   - 使用 CSV 文件存储数据
   - 自动管理待办事项 ID
   - 记录创建、完成、删除时间

4. **错误处理**
   - 完善的错误处理机制
   - 友好的错误提示

## 技术特点

1. **模块化设计**
   - 清晰的分层架构
   - 独立的数据模型
   - 分离的业务逻辑
   - 可扩展的存储层

2. **用户友好**
   - 简单的命令行界面
   - 直观的操作命令
   - 美观的输出格式

3. **代码质量**
   - 完整的错误处理
   - 类型安全
   - 内存安全
   - 线程安全

## 系统要求

- Rust 1.56.0 或更高版本
- 支持的操作系统：Linux, macOS, Windows 

## 开发顺序

1. 首先实现数据模型 (model.rs)
   这是最基础的部分,定义了数据结构和序列化方式

2. 然后实现存储层 (storage.rs)
   实现数据的持久化
   确保基本的 CRUD 操作可用

3. 接着实现业务逻辑层 (service.rs)
   在存储层基础上实现具体的业务功能
   添加错误处理和业务规则

4. 最后实现命令行接口 (main.rs)
   将所有功能通过命令行暴露给用户
   实现友好的交互体验
